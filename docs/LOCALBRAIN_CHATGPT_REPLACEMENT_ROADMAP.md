# LocalBrain ChatGPT Replacement Roadmap v1.0

> **How LocalBrain replaces daily ChatGPT use** for Steve's local work.  
> Doctrine: [Operating System Doctrine v2.0](./LOCALBRAIN_OPERATING_SYSTEM_DOCTRINE.md)

---

## Goal

```txt
ChatGPT becomes optional for work that touches Steve's files, projects, campaigns, and repos.
LocalBrain is the default: local context + safe actions + persistent memory.
```

ChatGPT remains for: fully cloud-only brainstorming with zero local context, when Steve chooses.

---

## Replacement Matrix

| ChatGPT today | LocalBrain path | When |
|---------------|-----------------|------|
| General chat | `/chat` + OpenAI backend | V1 (003) |
| Upload PDF / doc | Read approved local files | V1 (008) |
| "Search my stuff" | Explorer + search_files | V1 (006–007) |
| Writing drafts | Writing dashboard modes | OS v2–v3 |
| Code questions | Code studio + repo context | V1 (008+) |
| Project memory | SQLite + project profiles | V1 (012) |
| Custom GPTs | Agent registry (10 modes) | V1 (014) |
| Voice / mobile | **Future** | OS v4+ |

---

## LocalBrain Advantages Over ChatGPT

```txt
Files stay local — approved folders only
Sources shown with paths — no hallucinated file names
Actions possible (gated) — move, draft, index, backup
Persistent project context — ACU, VoteMatch, RedDirt in one OS
Campaign + civic agents — not generic assistant
No subscription lock-in for local index/search
OpenAI key is Steve's — backend only
```

## Phases

### Phase A — Chat parity (V1)

```txt
Multi-turn chat · agent selector · project selector
Tool calls visible in right panel
Missing-key friendly errors
```

### Phase B — Context richness (OS v2)

```txt
Explorer integration — chat knows current file selection
Folder summaries injected automatically
Conversation pinned to workstream
```

### Phase C — Writing + voice (OS v3)

```txt
Dedicated writing dashboard
Voice library (Steve, Kelly, grant, novel, etc.)
Draft versioning
```

### Phase D — Full daily driver (OS v4)

```txt
Steve opens LocalBrain before ChatGPT for 90% of tasks
Social + sysadmin in same shell
```

## Privacy Rule

```txt
Never send blocked file content to OpenAI
Never send API keys to frontend
Steve controls which folders are in context
```
