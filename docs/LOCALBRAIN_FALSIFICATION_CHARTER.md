## Steward promise

> **No implementation convenience is allowed to redefine the theory. Only evidence is.**

From here the mindset shifts from **architect** to **scientist**. The challenge is not inventing concepts — it is seeing whether reality agrees with those already defined.

---

## What would prove the theory wrong

Not what would improve it. Not what would extend it. What would **falsify** it.

None of the observations below are implementation bugs. They are challenges to the **theory itself**.

| Theory claim | What observation would seriously challenge it? |
| ------------ | ---------------------------------------------- |
| Memory before reasoning improves judgment | Systems that reason first **consistently outperform** under controlled conditions |
| Executive Questions organize cognition better than keyword retrieval | Keyword-first retrieval produces **measurably better** Judgment Quality |
| World Model Accuracy predicts Judgment Quality | Strong judgment **repeatedly occurs despite poor** World Model Accuracy |
| Mission Stack improves executive performance | Mission Stack **increases distraction** or reduces mission completion |
| Tension is a better optimization target than task priority | Priority-based systems **consistently outperform** tension-based systems on long-horizon outcomes |
| Cognitive Leverage improves when numerator ↑ or denominator ↓ | Improvements to JQ/WMA/MCP **do not correlate** with ECL-adjusted leverage over time |
| Cognitive Equilibrium beats single-metric optimization | Explicit tradeoff reasoning **underperforms** optimizing MCP alone |
| Conservation of Understanding holds | Wisdom/compression **destroys** traceable ancestry or verified memory |
| Agency (emergent observation) creates net leverage | Unprompted surfacing **increases ECL** without MCP/JQ gain across replications |
| Curiosity Engine improves Judgment Quality | Surfacing high-value questions **does not improve** JQ vs. control |
| Falsification search improves calibration | Active disconfirmation **does not improve** confidence calibration vs. passive update |
| Cognitive Compound Interest is real | Small JQ gains **do not compound** in Cognitive Capital over quarters |
| Theory scope (executive cognition only) | The framework **requires** modeling emotion/consciousness to explain executive outcomes |
| Architecture survives LLM disappearance | Core value **collapses** when inference is replaced by deterministic rules-only (violates independence) |

Record outcomes in [Cognitive Evidence Base](./LOCALBRAIN_COGNITIVE_EVIDENCE_BASE.md). Sustained counter-evidence → Theory amendment (v1.1+), not silent rewrite.

## Theory vs product (separate evolution)

Two things evolve independently:

| | Theory | Product |
| - | ------ | ------- |
| **Driven by** | Evidence · falsification · replication | Utility · UX · delivery |
| **Change rate** | Years (amendments) | Days (software) |
| **Relationship** | May diverge temporarily |

- A feature may be **commercially valuable** yet contribute nothing to the theory — acceptable.
- A validated insight may **not ship as a feature** immediately — also acceptable.

Separation protects both. Tag every slice: `theory-bearing` · `product-only` · `both`.

**LocalBrain is the reference implementation** of an operating theory for executive cognition — not the theory itself. Independent teams building different platforms from the same theory and obtaining similar outcomes would validate explanatory power beyond one codebase.

## Replication culture

One successful experiment is not enough. For every **Confirmed** hypothesis ask:

> Can another person reproduce this result?

Replication targets:

```txt
Different project · Different user · Different organization · Different time period
```

Hypothesis stays **Confirmed** only after replication record exists. First pass alone → `Provisional`.

## Three levels of success

When evaluating a hypothesis, distinguish — they **won't always align**:

| Level | Question |
| ----- | -------- |
| **Statistical** | Did the metric improve? |
| **Practical** | Did it meaningfully help the executive? |
| **Theoretical** | Did it strengthen or weaken the theory? |

Report all three in evidence entries. Statistical success without theoretical success → product feature, not theory validation.

## Canon preservation

**Never edit Theory v1.0 in place.**

```txt
Theory v1.0  →  frozen permanently (after peer review)
Theory v1.1  →  amendment (dated · evidenced · traceable)
Theory v1.2  →  amendment …
```

Historical record preserved. Intellectual evolution auditable — like Constitution amendments, not silent edits.

---

## Long-term corpus

Over years, accumulate:

```txt
Hypotheses → Implementations → Experiments → Outcomes → Amendments
```

Enables systematic analysis: *which cognitive interventions consistently improve executive judgment?*

Valuable internal asset whether or not published. Future development builds on **tested knowledge**, not intuition alone.

## Gate (before peer review)

1. Falsification conditions are **specific** enough to fail.
2. Each major theory claim maps to **at least one** falsifying observation.
3. Steward promise is accepted.
