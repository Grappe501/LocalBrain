# LocalBrain V1 — Launch Criteria

> **Rule:** If it is not on this checklist, it belongs in [Version 2](./VERSION2_BACKLOG.md).  
> **Mode:** [Implementation Mode](./LOCALBRAIN_V1_IMPLEMENTATION_MODE.md)

**V1 success:** An Empty LocalBrain Factory that manufactures sovereign executive institutions.

---

## Launch checklist

```txt
□ Factory installs cleanly
□ Empty Brain packages correctly
□ Birth Certificate generated
□ Identity created
□ Passport created
□ Authority active
□ License works
□ Provider Vault works
□ Executive Office works
□ Memory OS works
□ Communications Office works
□ Package upgrade works
□ Transfer works
□ Recovery works
□ Documentation complete
□ Beta customers onboarded
```

## Explicitly out of V1 scope

Everything not checked above — including but not limited to:

* Social media connector registry (PROD-003)
* Media Studio (PROD-004)
* Universal ingestion execution (CAP-FUT-UDI-001)
* Mobile PWA (PROD-006)
* Chief Compliance Officer packs (PROD-011)
* Multi-brain workspace beyond beta needs (027.1)
* Technology Office / Executive Engineering Memory
* Personal Steve data in permanent Memory OS before factory gate

Record those in [VERSION2_BACKLOG.md](./VERSION2_BACKLOG.md).
