# CF-002 — Full GitHub Portfolio Audit

**Status:** COMPLETE — portfolio triage baseline
**Date:** 2026-08-28

## Executive finding

The GitHub estate should be commercialized as product families, not as one company per repository. The strongest near-term families are SousChef / HomeChef AI, LocalBrain, CampaignOS commercial extraction from RedDirt, VoteMatch, and CanonForge generalized as a Knowledge OS.

## Founding Five

| Product family | Technical readiness | Commercial readiness | Disposition |
|---|---:|---:|---|
| SousChef / HomeChef AI | 90% | 72% | Accelerate |
| LocalBrain | 85% | 58% | Accelerate; narrow first ICP |
| CampaignOS / RedDirt extraction | 80% | 65% | Accelerate via clean commercial extraction |
| VoteMatch | 76% | 62% | Accelerate after auth/privacy hardening |
| CanonForge Knowledge OS | 70% | 45% | Validate market + extract engine |

## Second wave

ContactList / PeopleBase, Event Operations, FoundryOS, County Workbench, FieldSpark/field systems, and civic-education technology remain strategically valuable. FoundryOS is internal-first: it should become the shared software factory beneath the ventures before it is treated as an external product.

## Shared Foundry primitives

Authentication/RBAC/tenancy; billing and entitlements; AI provider/model routing; RAG/embeddings/knowledge ingestion; spreadsheet/file ingestion; identity matching and confidence scoring; human review queues; event/task/project primitives; relationship graph; audit/acceptance evidence; communication approval gates; analytics/cost attribution; deployment templates; phase acceptance; builder capability ledger.

## Priority for paid validation

1. SousChef
2. VoteMatch
3. CampaignOS
4. LocalBrain
5. CanonForge

This order optimizes for paid learning rather than theoretical TAM.

## Cross-portfolio blockers

- IP provenance and ownership
- separation of campaign/nonprofit/client assets from commercial assets
- standardized auth and tenant isolation
- billing and entitlement
- privacy/data retention
- production security baseline
- founder-independent onboarding/support
- AI/compute cost attribution
- legal review for political/election products
- corporate capitalization and contributor agreements before new builders create material IP

## Closeout

**CF-002: PASS.** Existing software assets are credible enough to support a venture-studio strategy. The limiting factor is disciplined commercialization and legal/economic architecture, not a shortage of ideas.
