The GitHub estate contains **80 repositories**, but not 80 independent businesses. The most important Foundry rule remains:

> **Commercialize products, not repository count.**

A repository can be one product, one component of a larger product, a proving ground, an implementation for one client/campaign, a book, a predecessor, or a research asset.

## 2. Audit grading

- **A — strong evidence:** current README/build architecture/status clearly identifies a product.
- **B — credible inference:** repository name/history and known project context are enough to classify family, but deeper technical audit is still required.
- **C — inventory-only:** insufficient product evidence today; retain and inspect before commercial allocation.

Disposition vocabulary:

- **ACCELERATE** — near-term commercialization.
- **TRAINING PRODUCT** — good Academy production environment; not automatically a Capstone.
- **CAPSTONE CANDIDATE** — suitable for a new accepted Master Build Plan.
- **INCUBATE** — credible, but later wave.
- **COMPONENT** — reusable Foundry primitive/module.
- **PROVING GROUND** — real implementation used to extract generic IP.
- **BOOK PRODUCT** — separate publishing/IP product with its own residual ledger.
- **IP REVIEW** — ownership, political/nonprofit/client, trademark, privacy, or licensing clearance required.
- **HOLD / CONTENT AUDIT** — not enough evidence yet.
- **ARCHIVE CANDIDATE** — likely predecessor once successor/IP mining is complete.

### Book residual doctrine

For a qualifying accepted Capstone book, the residual denominator should be publishing-specific:

`publisher/platform receipts`
`- returns/refunds`
`- printing/delivery/distribution`
`- direct editing/design/narration/production obligations`
`- direct advertising/launch spend`
`- authorized Foundry shared-service allocation`
`- reserves/taxes where applicable`
`= Distributable Book Residual`

Then apply the approved company/lead/team residual agreement. Copyright ownership, coauthor status, work-made-for-hire, royalty rights, audiobook/adaptation/foreign rights, and sale rights must be explicit before drafting work begins.
