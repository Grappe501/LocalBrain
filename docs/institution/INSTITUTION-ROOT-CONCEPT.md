# Institution — Root Concept (Reserved)

> **Status:** 🔒 **Root architectural concept · reserved** · Not a subsystem · 2026-07-05  
> **Capstone:** [First Principles Stack](../platform/FIRST-PRINCIPLES-STACK.md) — conceptual stopping point · 2026-07-05  
> **Gate:** Conceptual foundation for FED-001 · WSP-001 · ILG-001 · EPO-001 — not built during PRL-4

> **Institution = the highest sovereign organizational boundary.**

Everything below it belongs to **exactly one institution**. Everything above it belongs to the **individual**.

LocalBrain is not campaign software. It is an **Institution Operating System**. Campaigns are the first institution type being built — not the root abstraction.

---

## The hierarchy

```text
Person
   │
   ▼
LocalBrain                    ← individual sovereignty
   │
   ▼
Governed Sponsorship          ← institution recognizes this LocalBrain in this universe
   │
   ▼
Institution                   ← highest organizational boundary
   │
   ├── Universes               ← operational scopes (Campaign Ops · Volunteer · Finance · …)
   ├── Workspaces              ← temporary collaboration (WSP-001)
   ├── Services                ← trust domains (UCIE · Contact · VOP)
   ├── Ledgers                 ← institutional memory (ILG-001)
   └── Governance              ← health · readiness (EPO-001)
```

**A Campaign is not a universe.** A Campaign is an **Institution**. Its Campaign Universe is one operational universe created by that institution.

Likewise:

```text
Youth Movement          →  Institution
Youth Universe          →  Operational universe within that institution
```

---

## The institution boundary

```text
Person
   │
LocalBrain
   │
────────────────────────────
Institution Boundary
────────────────────────────
   │
Institution
   │
Universes · Workspaces · Services · Ledgers · Governance
```

| Side | Owns |
| ---- | ---- |
| **Above the boundary** | Person · LocalBrain · Personal Ledger |
| **Below the boundary** | Everything institutional — exactly one institution per artifact |

## Sponsorship — institution recognizes membership

A sponsor is not merely granting permissions.

> **This institution recognizes this LocalBrain as belonging to this universe.**

### Xavion — one identity · two institutions

```text
Person → LocalBrain → Sponsored by Youth Movement Institution → Youth Universe
Person → LocalBrain → Sponsored by Kelly Campaign Institution → Campaign Operations Universe
```

Same LocalBrain. Two institutions. Two sponsorships. Two universes. **One identity.**

### Sarah — lifetime without fragmentation

```text
Today:    Sponsored by Kelly Campaign Institution
Later:    Sponsored by New Nonprofit Institution
Never:    A second Sarah LocalBrain
```

Campaign ends. Kelly starts a nonprofit. **New institution · new sponsorship · new universe.** The graph grows. The person remains.

## Trust domains are institutional — not campaign-specific

| Trust Domain | Question | Scope |
| ------------ | -------- | ----- |
| Identity Trust | *Who is this?* | Any institution |
| Relationship Trust | *How do we know them?* | Any institution |
| Operational Trust | *Who is doing the work?* | Any institution |
| Governance Trust | *Is the institution healthy?* | Any institution |
| Collaboration Trust | *Who is allowed to think together?* | Any institution |

The architecture developed for campaigns is **institution-specific** — not campaign-specific.

## Campaign isolation — institution-to-institution

Cross-**institution** boundaries (especially between **campaign institutions**) remain sovereign:

> Information does not cross institution boundaries unless an explicit, authorized federation contract exists and the information is legally permitted to be shared.

Campaign coordination law applies between **campaign institutions**. The guarantee is architectural — see [Federation Sponsorship Model](../federation/FEDERATION-SPONSORSHIP-MODEL.md).
