## Trust level enum (frozen v1)

| Level | Code | Meaning | Default recall |
| ----- | ---- | ------- | -------------- |
| **System** | `system` | Generated by certified system logic | Included |
| **Verified** | `verified` | Confirmed by authoritative source | Included |
| **User Confirmed** | `user_confirmed` | Explicitly accepted by operator | Included |
| **Observed** | `observed` | Recorded but not independently verified | Included — lower rank |
| **Imported** | `imported` | External source awaiting validation | Quarantine rank |
| **Derived** | `derived` | Inferred from other memories | Included — cites sources |
| **Hypothesis** | `hypothesis` | Candidate — not yet accepted | Excluded from default recall |

**Rule:** Trust level is set at capture and may be **re-evaluated** via `trust_history` — memory body remains immutable.

## Trust vs lifecycle

| Dimension | Governs |
| --------- | ------- |
| **Lifecycle state** (S2) | Whether record exists in active authority |
| **Trust level** | How much weight recall ranking assigns |
| **Provenance** | Why we believe the capture is legitimate |

Independent dimensions — a Verified lifecycle record may have `derived` trust if synthesized from sources.

---

## Provenance envelope (S4 required fields)

Every memory object carries:

| Field | Purpose |
| ----- | ------- |
| `captured_by` | `identity_ref` of actor |
| `capture_method` | `direct` · `import` · `inference` · `system` |
| `source_ref` | KnowledgeSource, file, conversation, sensor |
| `consent_ref` | Link to consent record if required |
| `convention_provenance_version` | `CON-S4-2026-07` |

Provenance is **immutable** after capture. Corrections → new memory + `supersedes`.

## Trust transitions (allowed)

| From | To | Trigger |
| ---- | -- | ------- |
| `imported` | `user_confirmed` | Owner validates import |
| `imported` | `verified` | Authoritative source match |
| `observed` | `user_confirmed` | Operator attestation |
| `observed` | `verified` | Outcome or source confirmation |
| `hypothesis` | `observed` | Promoted to capture |
| `derived` | `user_confirmed` | Operator accepts inference |
| `system` | `verified` | Automated verification pass |

Downgrade requires audit reason — never silent.

## Memory Confidence (recall ranking)

Composite score for ordering — **not** a substitute for trust level:

```txt
confidence_score = f(trust_level, recency, corroboration_count, goal_alignment)
```

| Input | Source |
| ----- | ------ |
| `trust_level` | This document |
| `recency` | [TIME_MODEL](./TIME_MODEL.md) |
| `corroboration_count` | Graph `supports` edges |
| `goal_alignment` | Intelligence context — passed to recall, not stored |

---

## Imported memory quarantine

`imported` trust memories:

- Persisted normally
- Excluded from recommendations until promoted
- Visible to owner in review queue
- Graph edges to sources required before promotion

---

## Derived and hypothesis boundaries

| Level | Storage rule |
| ----- | ------------ |
| `derived` | Must have ≥1 `derived_from` edge · Intelligence proposes — Memory Engine commits via write pipeline |
| `hypothesis` | May exist only in Captured state · promotion requires capture gate + trust upgrade |

Intelligence **never** writes `verified` trust — attestation is Policy/User action.
