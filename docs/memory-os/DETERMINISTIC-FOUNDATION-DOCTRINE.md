# Deterministic Foundation Doctrine

> **Status:** Binding architectural doctrine · LocalBrain V1  
> **Authority:** Interpretive canon — [Architecture Book § Deterministic Foundation](../LOCALBRAIN_ARCHITECTURE_BOOK_v1.0.md#deterministic-foundation-doctrine)  
> **Engine:** ENG-MEM-001 Wave 1 establishes the substrate

---

## Core statement

LocalBrain is **not** deterministic end-to-end.

LocalBrain is **built on a deterministic foundation that enables explainable intelligence**.

---

## Two foundations (never confused)

| Foundation | Nature | Question |
| ---------- | ------ | -------- |
| **Deterministic Memory** | Constitutional substrate | What exists? |
| **Probabilistic Intelligence** | Advisory layer | What might this mean? |

Executive Intelligence may reason, recommend, hypothesize, plan, summarize, and strategize — but it **consumes** deterministic substrates. It does not replace them.

---

## Wave 1 property

Given the same inputs, Wave 1 canonical storage always produces the same outputs.

```text
Input → Canonical Episode      → Always identical
Input → Canonical Fact         → Always identical
Input → Canonical Artifact     → Always identical
Input → Canonical Conversation → Always identical
Input → Canonical DecisionCitation → Always identical (when implemented)
```

Nothing is probabilistic. Nothing is inferred. Nothing is generated at the substrate layer.

---

## Constitutional rule

```text
The deterministic substrate is constitutional.
Executive Intelligence is advisory.

Executive Intelligence may reason.
It may recommend.
It may hypothesize.
It may plan.

It may never rewrite the deterministic substrate.
```

---

## Defining sentence

> **AI should not be the memory of an institution. AI should reason over the institution's deterministic memory.**

Episode, Artifact, Fact, Conversation, and DecisionCitation are not "AI memories." They are **deterministic institutional records**. Intelligence becomes replaceable, improvable, and swappable because it is no longer responsible for preserving organizational truth.

---

## Model independence

When the LLM changes, Memory does not change. Episodes, Facts, Artifacts, and Conversations do not change. Only the reasoning layer changes. That is intentional.
