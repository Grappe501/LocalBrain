## Stop designing features. Design the science.

The architecture is complete:

```txt
Laws              (Axioms)
  ↓
Ontology          (Epistemology Convention)
  ↓
Governance        (World Model · Council)
  ↓
Cognition         (Agency · Tension · Time)
  ↓

  ↓
Experimental Science   (this document)
```

This layer does **not** change runtime architecture or the [Four Platform Systems](./LOCALBRAIN_FOUR_SYSTEMS.md). It changes **how the platform evolves** — every capability is an experiment with measurable hypotheses.

LocalBrain becomes a **continuously testable system of executive cognition**, not merely an application.

## Every capability begins with a hypothesis

Not: *Build Memory Engine.*

Instead: **Hypothesis H-027**

```txt
If memory recall is organized by Executive Questions instead of keywords,
then Mission Completion Probability will increase,
while Executive Cognitive Load decreases.
```

That can be measured. Every engine is an experiment.

| Engine | Example hypothesis |
| ------ | ------------------ |
| Mental Models | Modeling executive work patterns reduces unnecessary recommendations by 30%. |
| Curiosity | Surfacing unanswered high-value questions improves Judgment Quality. |
| Tension | Optimizing for tension reduction produces better long-term outcomes than optimizing task priority alone. |

**Hypothesis ID format:** `H-{slice_id}` · recorded in Burt packet · linked to Cognitive Trace outcomes · reviewed in System Evolution.

## Falsification

Actively try to prove recommendations **wrong** — confidence improves through disconfirmation, not optimism.

```txt
Recommendation: Visit Benton County first.

Falsification search:
  Recent polling
  Weather
  Volunteer availability
  Media schedule

→ Contrary evidence appears → confidence drops (appropriately)
```

Stronger than merely updating a score. Required for high-stakes recommendations per axiom compliance.

**Planned practice:** ENG-FAL-001 falsification pass · System 3 · logged on Cognitive Trace.

---

## Competing hypotheses

Do not prematurely converge on one explanation. Generate several:

```txt
Project is behind because…

A  Requirements changed      Confidence 61%
B  Engineering bottleneck    Confidence 57%
C  Mission drift             Confidence 49%
```

Surface meaningful disagreement to Steve when stakes are high. Ties to [Cognitive Diversity](./LOCALBRAIN_EXECUTIVE_METACOGNITION.md#cognitive-diversity).

## Evidence Debt

Like technical debt — conclusions resting on weak evidence:

```txt
Campaign strategy
Evidence Debt: High
→ Recommendation: Gather more evidence before acting.
```

**Planned metric:** evidence debt score per conclusion · feeds Curiosity · Self-Doubt · Agency withhold.

## Knowledge ROI

Which knowledge produced the most leverage?

```txt
Reading polling report
  → Changed three executive decisions
  → Saved ~12 hours
  → Knowledge ROI: Very High
```

Platform learns what information **actually matters** — not what was merely retrieved.

**Planned engine:** ENG-KROI-001 · System 4 · input to Wisdom and Knowledge Gravity.

## Cognitive Compression

Mark of expertise: ten memories become one understanding — nothing lost, representation improves.

```txt
14 county immersion reports
  → Pattern detected
  → New institutional understanding
  → 14 reports remain (conservation)
  → Understanding added
```

Must satisfy [Cognitive Conservation](./LOCALBRAIN_EXECUTIVE_COGNITION_AXIOMS.md#cognitive-conservation). Compression is additive, not destructive.

## Predictive Surprise

Reality surprises are highest learning priority:

```txt
Expected:   Donation increase
Reality:    Donation decrease
Surprise:   High
→ Learning priority: High
```

Feeds confidence calibration · Wisdom revision · World Model refresh.

## World Model Accuracy

Not LLM accuracy. **World Model accuracy.**

Every day estimate:

```txt
How closely does my World Model match reality?
```

Foundation beneath everything. If the World Model is wrong, memory · knowledge · judgment all suffer.

**Planned metric:** ENG-WMA-001 · System 2/4 · headline on System Evolution · input to [Judgment Quality](./LOCALBRAIN_EXECUTIVE_METACOGNITION.md) interpretation ("given what was **believed** knowable").

## Experimental protocol (Phase 2+ slices)

Every slice Burt packet includes:

```txt
1. Hypothesis ID (H-NNN)
2. Falsifiable prediction (what will improve · by what signal)
3. Measurement plan (before/after · Cognitive Trace · EPO/Evolution data)
4. Axiom compliance matrix
5. Falsification criteria (what would disprove the hypothesis)
6. Review date (accept · refine · reject hypothesis)
```

Rejected hypotheses are **published** — negative results strengthen the science.
