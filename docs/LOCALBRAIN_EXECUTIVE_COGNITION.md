## North star (10–20 years)

Not:

> "How do we build a better AI assistant?"

But:

> **"How do we build an executive cognitive system that can outperform today's assistants over the next 10–20 years?"**

**LLMs are one subsystem.** The brain is much larger — deterministic structure, memory, epistemology, agency, time, and verified learning. Models infer; cognition orchestrates.

Stop optimizing around prompts. Optimize around **continuous executive partnership**.

## Executive Cognition loop

Not "AI." A continuously operating cognition loop:

```txt
Observe
  ↓
Remember
  ↓
Understand
  ↓
Predict
  ↓
Imagine
  ↓
Decide
  ↓
Act
  ↓
Reflect
  ↓
Learn
  ↓
Evolve
```

**Reasoning is one stage — not the center.** [Understanding](./LOCALBRAIN_EXECUTIVE_EPISTEMOLOGY_CONVENTION.md) · prediction · counterfactual imagination · agency · decision · action · reflection all have distinct jobs.

Human executives don't wait. They **notice** → **anticipate** → **act**. LocalBrain should do the same — within policy, approval gates, and [Executive Cognitive Load](./LOCALBRAIN_EXECUTIVE_COGNITIVE_LOAD.md) (ECL) limits.

---

## Primary optimization objective

Most AI systems wait for prompts. Executive cognition:

> **Continuously observes reality, detects emerging tension, predicts likely futures, and proposes the smallest high-leverage intervention that meaningfully increases [Mission Completion Probability](./LOCALBRAIN_EXECUTIVE_INTENT.md) while minimizing Executive Cognitive Load.**

Value comes from knowing:

- when **not** to interrupt
- when to surface something **before** it becomes a problem
- when to stay **quiet** because the current trajectory is already optimal

That discipline is harder to build — and harder to copy — than a larger model or more tools.

## Executive Agency (capability — not System 5)

**Agency** decides:

> **Should anything happen at all?**

Initiative lives here — between prediction and decision.

### Pipeline extension

Epistemology alone is insufficient:

```txt
Question → Memory → Understanding → Prediction → Agency → Decision → Action
```

| Stage | Question |
| ----- | -------- |
| Question | What are we trying to answer? |
| Memory / Understanding | What do we know and conclude? |
| **Prediction** | What happens if Steve does nothing? |
| **Agency** | Should we surface, recommend, or initiate? |
| Decision | What does Steve choose? |
| Action | What executes (approval-gated)? |

### Agency loop

```txt
Observe
  ↓
Detect tension
  ↓
Predict future tension
  ↓
Recommend intervention
  ↓
Initiate (when policy allows)
```

**Emergent observation** — nobody asked:

```txt
ContactListSOS branch idle 11 days
Campaign debate in 9 days
Three grant deadlines overlap
Benton County travel underprepared
Chris hasn't replied
Disk usage accelerating
Five workspaces reference obsolete assumptions
Planning Engine not rerun since survey changed
```

The platform **noticed**. That is agency's input — not a user prompt.

## Tension

Not urgency. Not priority alone. **Tension.**

Everything in the system carries a tension score — how much unresolved pressure exists in a domain if Steve does nothing.

```txt
Campaign     92
Writing      15
Novel        48
Taxes        83
Travel       61
Health       74
```

The brain's job:

> **Reduce total system tension** — not merely answer prompts.

Tension feeds Agency and [Attention Budget](./LOCALBRAIN_EXECUTIVE_INTENT.md). High tension + high MCP opportunity + acceptable ECL → surface. Low tension + optimal trajectory → stay quiet.

**Planned engine:** ENG-TEN-001 · System 3 (Executive Intelligence).

## Time: Trajectories and Momentum

Phase 1 is largely **spatial** (workspaces · assets · knowledge · relationships). Executives live in **time**.

### Trajectories

Not snapshots — direction over time:

```txt
Campaign trajectory      improving
Novel trajectory         stalled
Business trajectory      accelerating
Health trajectory        declining
```

Predicting, not merely describing. **Planned engine:** ENG-TRJ-001 · System 4 (Executive Evolution).

### Momentum

State plus motion:

```txt
ContactListSOS
  State      Healthy
  Momentum   Increasing
  Velocity   Fast
  Direction  Toward launch
```

Closer to how humans think about work in progress. **Planned engine:** ENG-MOM-001 · System 4 (Executive Evolution).

## Mental Models (System 2)

Not memories. **Models** — continuously tested patterns about how Steve works:

```txt
Steve prefers large architectural passes
Steve avoids small iterative edits
Steve works best late evening
Steve switches rapidly between domains
Steve likes visual dashboards
Steve requires strategic context before tactical work
```

These are derived, revisable, evidence-backed — distinct from [verified memory](./LOCALBRAIN_EXECUTIVE_EPISTEMOLOGY_CONVENTION.md). **Planned engine:** ENG-MML-001 · System 2 (Executive Memory OS).

---

## Counterfactual Thinking (System 3)

Difference between average and exceptional executives — exploring alternate futures:

```txt
If we postpone migration...
  ↓ Readiness drops 4%
  ↓ Memory work begins sooner
  ↓ Technical debt remains
  ↓ Probability of rework rises 11%
```

Not planning alone. **Imagining** branches before deciding. Ties to [Simulation as first-class](./LOCALBRAIN_ACTION_PIPELINE.md). **Planned engine:** ENG-CFX-001 · System 3 (Executive Intelligence).

**Prediction engine:** ENG-PRE-001 · System 3 — "What happens if Steve does nothing?"
