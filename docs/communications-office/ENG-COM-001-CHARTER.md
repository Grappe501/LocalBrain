Evidence must demonstrate, at minimum:

| # | Requirement |
| - | ----------- |
| E1 | Every substantive claim is traceable to the Evidence Package |
| E2 | Uncertainty is preserved rather than hidden |
| E3 | Evidence boundaries are preserved |
| E4 | Unsupported claims are withheld rather than generated |
| E5 | The output remains advisory and never crosses into Policy or Action |
| E6 | The reasoning remains within the requested communication scope |

Implementation slices · behavioral tests · contracts · and PMO acceptance ceremonies **emerge from** satisfying these requirements — they are not predefined in this charter.
