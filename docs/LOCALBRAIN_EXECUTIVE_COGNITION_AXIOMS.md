# Executive Cognition Axioms

> **Status:** Constitutional law — non-negotiable · Phase 2+  
> **Rule:** Every engine, API, prompt, and workflow must be **provably consistent** with these axioms.  
> **Parent:** [Constitution Article XIV](./LOCALBRAIN_CONSTITUTION.md#article-xiv--executive-cognition-axioms) · [Executive Epistemology Convention](./LOCALBRAIN_EXECUTIVE_EPISTEMOLOGY_CONVENTION.md)

---

## Long-term ambition

> **Build a governed executive cognition platform whose reasoning remains traceable, whose judgment continuously improves through experience, whose understanding stays coherent as reality changes, and whose architecture remains independent of any particular AI model.**

Future AI advances become **interchangeable components**. Enduring value comes from cognitive architecture and governance — not whichever model is state of the art today.

---

## Architecture inversion

Most AI systems are built outside-in:

```txt
UI → Chat → Tools → Memory
```

LocalBrain is built inside-out:

```txt
Reality → World Model → Memory → Knowledge → Judgment → Action → UI
```

The UI is **one projection** of a deeper cognitive architecture — not the architecture itself.

---

## The seven axioms (laws)

Not implementation details. **Laws.** Once fixed, theorems follow.

### Axiom 1 — Reality is sovereign

> **The platform models reality. It never substitutes for it.**

Every belief, recommendation, and plan must ultimately point back to observable evidence or explicitly identified assumptions.

---

### Axiom 2 — Memory precedes reasoning

> **No reasoning occurs until relevant memory has been considered.**

Not optional. Not a best practice. Binding gate before inference, recommendation, or action proposal.

See [Article XIII](./LOCALBRAIN_CONSTITUTION.md#article-xiii--executive-principle).

---

### Axiom 3 — Questions govern cognition

> **Everything begins with a question — not data, not prompts.**

No question means no reason to assemble context. See [Executive Question Registry](./LOCALBRAIN_EXECUTIVE_QUESTION_REGISTRY.md) · [Epistemology Convention](./LOCALBRAIN_EXECUTIVE_EPISTEMOLOGY_CONVENTION.md).

---

### Axiom 4 — Every conclusion has ancestry

Every conclusion must be able to answer:

```txt
Which question?
Which memories?
Which evidence?
Which assumptions?
Which judgment lenses?
Which unknowns?
```

Ancestry is never lost. Preserved in [Cognitive Trace](./LOCALBRAIN_EXECUTIVE_METACOGNITION.md#cognitive-trace).

---

### Axiom 5 — Uncertainty is information

Unknowns are not failures. Confidence is not certainty. Self-doubt is a feature.

The platform becomes increasingly good at **recognizing** uncertainty rather than hiding it. See [Unknowns](./LOCALBRAIN_COGNITIVE_GOVERNANCE.md#unknowns) · [Intellectual Humility](./LOCALBRAIN_EXECUTIVE_METACOGNITION.md#intellectual-humility).

---

### Axiom 6 — Time changes truth

Some things expire. Some become obsolete. Some become stronger. Knowledge has a **temporal dimension**.

The [World Model](./LOCALBRAIN_COGNITIVE_GOVERNANCE.md#world-model) must know that. See [Trajectories](./LOCALBRAIN_EXECUTIVE_COGNITION.md) · memory lifecycle · Strategic Clock.

---

### Axiom 7 — Decisions change reality

Once action occurs, reality changes. World Model changes. Memory changes. Understanding changes.

Everything downstream recognizes that **the world itself has been altered**. Closed loop: Action → Outcome → Learning → World Model refresh.

## Cognitive Invariants

Never change regardless of which LLM exists. **Vendor-independent.**

```txt
Traceability
Provenance
Explainability
Reversibility (where policy allows)
Separation of observation from interpretation
Separation of memory from belief
Separation of belief from judgment
```

If GPT-10 disappears tomorrow, nothing about the architecture changes — only inference adapters.

---

## Cognitive Conservation

Nothing disappears. It **transforms**. Earlier forms still exist.

```txt
Observation
  ↓
Memory
  ↓
Knowledge
  ↓
Understanding
  ↓
Wisdom
```

**Wisdom never overwrites memory. Memory never overwrites observation.**

Preservation makes auditability possible. Violating conservation is an axiom breach.

## Derived capabilities (axiom-consistent)

Capabilities inside [Four Platform Systems](./LOCALBRAIN_FOUR_SYSTEMS.md) — not new pillars.

### Executive Coherence

> **Does my understanding still fit together?**

```txt
Campaign doctrine says A
Recent decisions imply B
World Model implies C
→ Coherence problem detected
```

Not because anything is false — because they **no longer align**. Among the most valuable long-term capabilities.

**Planned engine:** ENG-COH-001 · System 3 (Intelligence) · World Model input.

---

### Knowledge Gravity

Not all knowledge is equal. Every knowledge object carries **gravitational influence**:

```txt
Campaign strategy     Gravity 97
Travel itinerary      Gravity 12
Random receipt        Gravity  2
```

High-gravity knowledge attracts attention, validation, and protection. When high-gravity assumptions change, the platform immediately knows consequences are broad.

**Planned engine:** ENG-KG-001 · System 2 (Executive Memory OS).

---

### Cognitive Resilience

> **If this knowledge disappeared tomorrow… how much of the system breaks?**

Identifies single points of failure in institutional knowledge and weak documentation. Feeds [Curiosity Engine](./LOCALBRAIN_COGNITIVE_GOVERNANCE.md#curiosity-engine) and Evolution priorities.

**Planned engine:** ENG-CRL-001 · System 4 (Executive Evolution).

---

### Executive Identity

Not user identity. **Cognitive identity** — evolving, evidence-based models of:

```txt
Long-term objectives · Decision philosophy · Risk tolerance
Preferred planning style · Communication style · Strategic habits
```

Revised when behavior changes — not hardcoded personality. Extends [Mental Models](./LOCALBRAIN_EXECUTIVE_COGNITION.md) · [Digital Twin](./LOCALBRAIN_DIGITAL_TWIN.md) domain "You."

**Planned engine:** ENG-EID-001 · System 2 (Executive Memory OS).
