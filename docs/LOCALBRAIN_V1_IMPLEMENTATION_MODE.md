# LocalBrain V1 — Implementation Mode

> **Effective:** Architecture feature freeze — launch path only  
> **V1 wins by launching.** V2 wins by evolving.

```txt
==========================================
LOCALBRAIN V1
ARCHITECTURE COMPLETE
IMPLEMENTATION MODE
NO NEW DOCTRINE
==========================================
```

The job is no longer to invent the system. **Build the system already designed.**

---

## Feature freeze (until V1 launch)

```txt
NO NEW DOCTRINE
NO NEW RESERVED CAPABILITIES
NO NEW OFFICES
NO NEW COGNITIVE LAYERS
```

### Allowed

* Finish existing implementation
* Fix bugs
* Polish UX
* Complete certification
* Complete testing
* Complete documentation
* Ship

### Not allowed

* New architectural documents (except V2 backlog entries)
* New `futureCap` / reserved capability registry entries
* New office or department definitions
* New cognitive layers

**Every new idea** → [VERSION2_BACKLOG.md](./VERSION2_BACKLOG.md) and wait.

---

## V1 success definition

**Not:** We built everything we imagined.

**Yes:** We launched an **Empty LocalBrain Factory** that can manufacture sovereign executive institutions.

**Burt stops receiving design work.** Every new Burt packet **must** begin with:

```txt
## PROJECT STATUS

Architecture Phase: COMPLETE
Doctrine: FROZEN
Reserved capability creation: DISABLED
Mission: Execute the existing roadmap.

If a new architectural idea is discovered, record it in VERSION2_BACKLOG.md
and continue implementation. Do not expand doctrine.
```
